# Contribution Guidelines

Suggestions are welcome. Open a pull request that edits [`README.md`](README.md), or open an issue if you are not sure where something belongs.

## What gets listed

- **On topic:** about lucid dreaming, dream research, or practices that directly support lucid dreaming.
- **Available:** released and publicly reachable. Pre-orders, waitlists and unreleased games are added once they ship.
- **Still working:** links work and apps can be installed from their store. Apps with no update for more than two years may be removed. Older books, films, studies and podcast archives are fine.
- **Recommended:** something you would point a friend to, not just something that exists.

## Adding an entry

1. Add one resource per pull request where possible, and say in the pull request why it belongs on the list.
2. Use the format `- [Name](link) - Description.`
3. Write the description as one plain, factual sentence that starts with a capital letter and ends with a period. Do not repeat the name or copy marketing text.
4. Add the entry to the end of its section. Research Studies are in year order, so place studies by year.
5. For research studies, write the title in title case followed by the authors and year, for example `(Konkoly, K. R., et al. 2024)`. Link the DOI and base the description on the abstract.
6. Check that `npx awesome-lint README.md` passes.

## Removing or correcting an entry

Open a pull request or issue with the reason, such as a dead link, an app that is no longer available, or a description that does not match its source.
